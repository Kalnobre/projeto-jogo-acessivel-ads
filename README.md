# 🎮 Jogo da Memória de Som (Projeto ADS)

Projeto da disciplina de Fundamentos de Programação Web (4º Período ADS), focado na criação de um jogo de memória 100% acessível via teclado e leitores de tela para usuários com deficiência visual.

## 👥 Integrantes do Grupo
* Kalebe Nobre de Aquino
* Aline Pereira dos Santos
* João

## 🎯 Objetivo
Demonstrar a aplicação de HTML semântico, atributos ARIA e manipulação de áudio com JavaScript para criar uma experiência de usuário inclusiva, seguindo as melhores práticas de desenvolvimento web.

## 🛠️ Tecnologias
* **HTML5:** Estrutura semântica (`<button>`) e atributos ARIA (`role=grid`, `aria-live`).
* **CSS3:** Grid Layout e foco visível para navegação por teclado.
* **JavaScript (ES6+):** Arquitetura modular (MVC), Web Audio API (pré-carregamento) e manipulação do DOM.

## 🚀 Como Executar
1.  Clone este repositório.
2.  Abra o arquivo `index.html` em um navegador.
3.  **Recomendado:** Use a extensão "Live Server" do VS Code para evitar problemas de segurança (CORS) ao carregar os arquivos de áudio.
